# Coxswain MCP tools

Generated by `coxswain_mcp --tools`; do not edit by hand.

## `task_create`

Create a task (status open). blocked_by lists ids of tasks that must be done before it can be claimed. Returns the new task.

Input schema: `{"type":"object","properties":{"title":{"type":"string"},"description":{"type":"string"},"blocked_by":{"type":"array","items":{"type":"integer"}}},"required":["title"]}`

## `task_list`

List tasks, optionally only those with a status (open, claimed, done) or an assignee. Each task is shown in full; blocked is true while a task it waits on is not done.

Input schema: `{"type":"object","properties":{"status":{"type":"string","enum":["open","claimed","done"]},"assignee":{"type":"string"}}}`

## `task_get`

Show one task by id, with its notes.

Input schema: `{"type":"object","properties":{"id":{"type":"integer"}},"required":["id"]}`

## `task_claim`

Claim an open task for an agent, atomically: if another agent got there first, or the task is blocked by unfinished tasks, it is refused. agent defaults to the server's --agent name.

Input schema: `{"type":"object","properties":{"id":{"type":"integer"},"agent":{"type":"string"}},"required":["id"]}`

## `task_release`

Give a claimed task back (status open). Only its assignee may release it unless force is true.

Input schema: `{"type":"object","properties":{"id":{"type":"integer"},"agent":{"type":"string"},"force":{"type":"boolean"}},"required":["id"]}`

## `task_complete`

Mark a claimed task done. Only its assignee may complete it unless force is true. An optional note is added.

Input schema: `{"type":"object","properties":{"id":{"type":"integer"},"agent":{"type":"string"},"note":{"type":"string"},"force":{"type":"boolean"}},"required":["id"]}`

## `task_note`

Append a note to a task (a handoff, a finding, a question). Anyone may add one.

Input schema: `{"type":"object","properties":{"id":{"type":"integer"},"text":{"type":"string"},"agent":{"type":"string"}},"required":["id","text"]}`
